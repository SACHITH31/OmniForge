## [0.2.0]

### Added

- Convert JPEG and PNG images, adjust JPEG compression, and create PDFs from images on the device.
- Import PDFs and manage recent local files with filename search.
- Preview saved JPEG, PNG, and PDF outputs. Navigate PDFs by page number or rendered thumbnail, and zoom in on the current page.
- Select PDF text and search across pages on Android 15 or newer.
- Save a PDF page as a separate JPEG and return to the original PDF after previewing it.
- Share saved files, export copies to an Android document folder, and open them with compatible apps.
- Choose light, dark, or system appearance and keep favorites in a sortable file library.
- Preview and export PNG page images and UTF-8 text extracted from PDFs on compatible Android devices.
- Preview and save replacements of supported PDF text objects with page-bound, neighboring-text, and visual checks.

### Fixed

- Bundle JavaScript in the standalone Android APK so it launches without Metro.
- Keep workspace controls clear of Android system bars and return from results to their originating screen.
